# Manual Testing Checklist — Urban Bloom Florist

Record the date, browser, viewport size and actual result when you carry out each test. Do not mark a test as passed until you have performed it.

| Area | Test | Result / notes |
|---|---|---|
| Navigation | Open each of the five HTML pages from the navigation | To be completed by student |
| Navigation | Open and close the mobile menu; test Escape key and menu links | To be completed by student |
| Products | Confirm all eight required products and indicative prices are displayed | To be completed by student |
| Filtering | Test All, Birthday, Anniversary, Everyday, Sympathy and Corporate filters | To be completed by student |
| Enquiry | Submit with required fields empty and confirm browser validation appears | To be completed by student |
| Enquiry | Enter an invalid email and confirm it is rejected | To be completed by student |
| Enquiry | Submit valid details and confirm demonstration feedback appears | To be completed by student |
| Responsive | Check desktop, tablet and mobile layouts | To be completed by student |
| Accessibility | Navigate with keyboard and check visible focus indicators | To be completed by student |
| Images | Confirm all local SVG illustrations load after disconnecting from the internet | To be completed by student |
| Links | Check phone, email, internal links and enquiry calls to action | To be completed by student |
| ZIP | Extract the final ZIP and open `index.html` | To be completed by student |

## Known scope limitation
The contact form is a front-end demonstration only. It does not send enquiries to a real inbox or save submissions.
