# Urban Bloom Florist — Final Website Project (Assignment 2B)

## Open the website
1. Extract the ZIP folder.
2. Open `index.html` in a modern web browser.
3. Use the navigation to visit Home, Flowers & Gifts, Weddings & Events, Corporate, and Delivery & FAQs.

## Project files
- `index.html` — homepage
- `flowers.html` — eight required products, gift add-ons and occasion filtering
- `weddings.html` — wedding and event services and indicative prices
- `corporate.html` — corporate services and indicative pricing
- `contact.html` — contact details, opening hours, delivery information, FAQs and enquiry form
- `style.css` — shared styles and responsive layouts for inner pages
- `script.js` — mobile navigation, active-page navigation, product filtering and form feedback
- `images/` — locally stored original SVG floral illustrations used by the site

## Important functionality notes
- The enquiry form performs browser-side required-field and email validation and displays a confirmation message. It does not transmit, email or store information because this is a front-end-only assignment project. The form includes optional event details such as guest count, budget and preferred style/colours.
- Product filtering is implemented with vanilla JavaScript and filters by occasion/category. Product enquiry links carry the selected arrangement into the enquiry message.
- The website does not include online ordering, payment processing, a database or a back-end service, in line with the Case Pack.
- The fictional contact details and business information are those supplied in the Urban Bloom Florist Case Pack.

## Technology and credits
The website uses HTML5, CSS3, vanilla JavaScript and original SVG illustrations created for this project. No third-party JavaScript or CSS framework is required. The original project design and page structure have been retained and extended for the final website.
